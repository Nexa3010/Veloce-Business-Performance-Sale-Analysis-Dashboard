# 📊 Veloce - Business Performance & Sales Analysis Dashboard

Veloce is a modern, interactive sales analytics dashboard built using **HTML, CSS, and JavaScript**. It provides real-time business insights through dynamic charts, KPI cards, and filtering options, enabling users to analyze sales performance efficiently.

---

## 🚀 Features

- 📈 Interactive analytics dashboard
- 💰 Revenue & Sales KPIs
- 🌍 Country-based filtering
- 👥 Customer and Gender filters
- 📅 Time-based sales analysis
- 📊 Multiple interactive charts
- 🌙 Dark Theme UI
- ⚡ Fast and responsive interface
- 📂 JSON-based dataset
- 🔄 Dynamic dashboard updates

---

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/Nexa3010/Veloce-Business-Performance-Sale-Analysis-Dashboard
```

2. Open the project folder

```bash
cd veloce-dashboard
```

3. Open `index.html` in your browser.

No additional installation is required.

## 📊 Dashboard Overview

The dashboard provides insights including:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Sales by Country
- Sales by Category
- Monthly Revenue Trends
- Customer Demographics
- Product Performance

---

## 🎯 Filters

Users can filter data using:

- Country
- Gender
- Product Category
- Time Period

The dashboard updates automatically based on selected filters.
